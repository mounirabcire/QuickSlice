## About This Project 🚀
**QuickSlice** is a modern pizza delivery web application designed to provide a seamless and enjoyable online ordering experience. This React-based app allows users to explore a variety of pizza options, and have them delivered straight to their doorstep.

## Technologies 🛠️
- `sass`
- `React`
- `Framer Motion & Gsap`

## Features 💡
- Browse Menu: Explore a wide range of pizza options, including vegetarian, non-vegetarian, and custom pizzas.
- User Authentication: Secure login and registration system for personalized experiences.
- Cart Management: Add items to the cart, view the cart, and manage orders.
- Responsive Design: Fully responsive layout for optimal viewing on all devices.

## Learnings 📚
- Gsap animations

## Running the Project 🚦
1. Clone the repository to your machine.
`https://github.com/mounirabcire/QuickSlice.git`

2. Install dependencies:
`cd QuickSlice `
`npm install`

3. Start the development server:
`npm run dev`

4. Open the address shown in your console on your web browser
